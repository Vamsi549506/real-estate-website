My Experience Building This Website

Before this project, I knew some HTML and CSS but had not built a complete multi-page website. Building Tampa Bay Homes taught me how the pieces of a front end work together: HTML for structure, CSS and Bootstrap for a consistent look on every screen size, and JavaScript for interactivity.

The most challenging part was the Manage Listings page. I learned how to store data in a JavaScript array, redraw the table whenever the data changes, and handle Create, Read, Update, and Delete actions from a single form. I also learned to use Git and GitHub to track my work and publish the site with GitHub Pages.

How I Built It

  1. Planned the four pages, the layout of each page, and the color scheme.
  2. Set up the project by forking the course starter repository on GitHub and cloning it in VS Code.
  3. Built the shared layout: the same navigation menu and footer on every page, styled from one CSS file.
  4. Created the Home page with real Tampa Bay market figures, featured properties, and neighborhood overviews.
  5. Wrote the mock CRUD logic in JavaScript to add, view, edit, delete, search, and filter listings.
  6. Added charts with Chart.js using Realtor.com data published by FRED.
  7. Tested and published the site on desktop and mobile widths, then deployed it with GitHub Pages.
